## About Me

I am a **PhD researcher** focused on **geometric deep learning** for biomedical applications.  
My work combines theory and practice in:
- shape analysis and manifold learning
- graph and manifold neural networks
- brain connectivity modeling
- robust, reproducible ML pipelines for medical data

## Research Interests

| Area | Focus |
|---|---|
| Geometric Deep Learning | Non-Euclidean learning on meshes, graphs, and manifolds |
| Shape Analysis | Representation learning for anatomical structures |
| Manifold Neural Networks | Architectures respecting geometry and topology |
| Brain Connectivity | Modeling structural/functional connectomes |
| Biomedical AI | Clinically relevant, interpretable, and reproducible systems |
