# Security Policy

## Supported Scope

This repository contains profile website and research-profile metadata.

- Public web/profile content is in scope.
- Linked external repositories may have their own security policies.
- **Restricted-access datasets are not included in this repository.**

## Reporting a Vulnerability or Privacy Issue

If you find a security, privacy, or sensitive-data exposure issue:

1. **Do not open a public issue with sensitive details.**
2. Report privately by emailing: `security-contact@example.org`
3. Include:
   - short description of the issue,
   - affected file/path and commit (if known),
   - impact assessment,
   - reproduction steps (if applicable).

## Response Expectations

- Initial acknowledgement target: within **7 days**.
- Triage and remediation timeline depends on severity and reproducibility.
- Confirmed issues will be fixed and publicly documented when safe.

## Sensitive Data Handling

- Do not commit API keys, tokens, credentials, private identifiers, or private infrastructure paths.
- Use placeholders for personal/private contact details unless explicitly intended for public disclosure.
